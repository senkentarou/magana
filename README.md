# Magana

[English](README.en.md) | **日本語**

左 ⌘ を押して離すと英数、右 ⌘ を押して離すとかなに切り替わる。US 配列の Mac 向けの
メニューバー常駐アプリ。

切り替わるのは押して離したときだけなので、⌘C や ⌘+クリック、長押しはこれまでと
変わらない。

仮想キーボードドライバも設定ファイルも持たない。必要な許可はアクセシビリティの 1 つ。

## 特徴

- 左右の ⌘ に 英数 / かな を割り当て。入れ替えも、片側を無効にもできる
- アプリケーション単位の設定。⌘ をそのまま透過させる、または前面で 英数 / かな に固定する
- JIS キーボードの接続中は自動的に停止する
- 押下と長押しを分ける時間を調整できる
- メニューバーからの一時停止、ログイン時の自動起動、アプリ内アップデート

## プライバシー

- ⌘ 以外のキーは、押されたという事実だけを扱う。キーコードも文字も保持せず、ログにも残さない
- 通信はアップデートの確認とダウンロードのみ

## 動作要件

macOS 14 Sonoma 以降。アクセシビリティ権限。

## インストール

[Releases](https://github.com/senkentarou/magana/releases) から
`Magana-<version>.zip` をダウンロードし、展開した `Magana.app` を `/Applications`
に配置する。

初回起動でアクセシビリティの許可を求められる。**システム設定 › プライバシーと
セキュリティ › アクセシビリティ**で Magana を有効にすれば動き出す。

## ビルド

```
make run     # ビルド、署名、/Applications に配置して起動
make check   # lint → build → test
```

## アーキテクチャ

| ターゲット | 役割 |
|---|---|
| `MaganaCore` | 判定ロジック。AppKit に依存せず `swift test` で検証できる |
| `Magana` | SwiftUI / AppKit のシェル。OS への呼び出しはすべてここ |
